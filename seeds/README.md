# Seeds

Ready-made project folders for the autopilot: a brief, reference images and a start script. Copy one out of this
repository before starting it (a project must be its own git repository):

    cp -R ~/waypoint/seeds/vesper-road ~/waypoint-projects/ && ~/waypoint-projects/vesper-road/start.sh

The reference images belong to their creators and are here with permission, as style references only (see each
seed's `references/ART.md`). Seeds are not part of the shareable export.
